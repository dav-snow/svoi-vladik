# Аватары приложения

[Архив: шесть PNG с прозрачным фоном](SVOI_VLADIK_APP_AVATARS_v1.zip).

[Правила выбора и открытия за квесты](../../docs/PROFILE_AVATARS.md).

Сразу доступны маяк, кораблик и солнце. Компас, краб и мост открываются после завершения соответственно одного, двух и трёх разных квестов. Подключено в профиле (задача 019): UI использует WebP-копии 256 px из `frontend-design/dist/assets/avatars/`, оригиналы остаются в архиве.
