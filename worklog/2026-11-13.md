## Как гонять тесты (обход медленного PyPI)

```sh
# через зеркало (быстро, проверено):
docker run --rm -v "$PWD":/src -w /src/backend python:3.11-slim sh -c \
  "pip install -q -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com -r requirements-dev.txt && python -m pytest -q"

# либо официальный PyPI с увеличенными таймаутами:
docker run --rm -e PIP_DEFAULT_TIMEOUT=120 -e PIP_RETRIES=10 -v "$PWD":/src -w /src/backend \
  python:3.11-slim sh -c "pip install -q -r requirements-dev.txt && python -m pytest -q"
```
