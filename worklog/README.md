# Журнал работы (worklog)

Здесь фиксируются выполненные задачи по проекту «Свой Владик», чтобы можно было
отследить, что и когда делалось. Один файл на день.

## Структура

- `README.md` — этот индекс и правила ведения.
- `YYYY-MM-DD.md` — отчёт за конкретный день: задачи, коммиты, ветки, проверки,
  известные проблемы и что дальше.

## Правила

- В конце рабочего дня (или по запросу) добавляется/дополняется файл текущей даты.
- В отчёте указываются: ветка, хэши коммитов, затронутые файлы, чем проверено,
  отклонения и известные долги.
- Секреты (пароли, ключи, приватные хосты) в журнал **не** попадают.
- Журнал не заменяет `prompts/` (там ТЗ задач) и `docs/` (там продуктовые
  документы и контракт API).
