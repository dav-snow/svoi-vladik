# Клиент Свой Владик

Адаптивный интерфейс для ПК и телефона с настоящей картой Ленинского района. Белые поверхности, оранжевый акцент, мягкие рамки и углы. Код в dist работает без компилятора; данные и проверку ответов предоставляет FastAPI с того же адреса.

Стеклянная версия: полупрозрачные панели с blur/saturate, мягкие блики и кнопки с тактильным нажатием. `motion.js` превращает нажатую кнопку в диалог (FLIP, 440 мс), плавно перестраивает окно при смене содержимого и возвращает его к исходному элементу при закрытии (200 мс). Escape, клик снаружи и кнопка закрытия используют один механизм; фокус остаётся внутри modal и возвращается к живому trigger. Для reduced motion нет WAAPI-масштабирования; для reduced transparency и браузеров без blur предусмотрена плотная поверхность. Изменения этого этапа ограничены папкой клиента, API и сервер не менялись.

Проверки: [glass-motion.md](review/glass-motion.md). Файлы: `glass.css`, `motion.css`, `motion.js`. Запуск тестов только фронтенда: `node --test frontend-design/tests/geolocation.test.mjs frontend-design/tests/motion.test.mjs`.

## Запуск

Из корня проекта: npm.cmd start или двойной щелчок по start.cmd. Адрес: http://127.0.0.1:8000/ . Окно сервера оставить открытым. Зависимости Python и первые шаги: ../docs/RUN_LOCAL.md.

node frontend-design/preview.mjs сохраняет старый адрес http://127.0.0.1:5173/ как прокси к общему приложению. Сначала нужен основной сервер. Открытие index.html как файла не заменяет запуск API.

## Рабочие возможности

- 14 активных районных кандидатов из общего каталога; поиск, категории, карточки, источники и закладки.
- Помощница из шести исходных состояний: приветствие, поиск, истории, направление и реакция на явную отметку пользователя. Это сценарные подсказки, свободного ИИ-чата нет.
- GPS по кнопке и ручной старт. Приблизительные расстояния по прямой, радиус 300 м–5 км, обновление и очистка позиции. Координаты только в памяти страницы, без API, URL и хранилищ.
- Четыре прогулки: выбор остановки, порядок на карте, переход к следующей точке через 2ГИС, ручная отметка прибытия и завершение. Пунктир не является рассчитанным пешеходным путём.
- Четыре квеста на 3/3/5/5 заданий: факты с источниками, отдельно художественные реплики, повтор неверного ответа, серверная проверка, сохранение прогресса, сброс и локальный прогресс завершения.
- Manifest и service worker для оболочки. API, геопозиция и ответы не кэшируются; офлайн-проверка квеста не обещается. Настоящая карта и веб-шрифт требуют сети; при отсутствии WebGL доступен схематичный режим со списком.

Все места имеют draft-статус. Три неопределённых кандидата не активны; их причины — ../docs/CONTENT_IMPORT.md. Цены, часы, длительность и длина маршрута не выдуманы. Полевой проверки переходов не было.

## Структура

index.html — экраны; app.js — карта, GPS и сценарии; styles.css — базовая адаптация; polish.css — финальная отделка; mascot.js/css и assets/mascot — помощница; map-style.json — локальный стиль OpenFreeMap. Серверный контракт: ../INTEGRATION.md. Данные каталога: ../data/places.json, прогулки и квесты — в соседних JSON. Старые три GeoJSON-кандидата сохранены как исходные материалы, приложение загружает актуальный каталог из API.

## Проверка и источники

Проверки и ограничения перечислены в ../docs/INTEGRATION_QA.md. Исходники PNG команды сохранены в ../assets/mascot; прозрачные WebP легче на 92%. Иконки SVG — авторские условные рисунки, не фотографии объектов.

Подложка: OpenFreeMap Positron (https://openfreemap.org/quick_start/), MapLibre GL JS 4.7.1 (https://maplibre.org/), геоданные OpenStreetMap ODbL. Атрибуции сохранены. Навигация через 2ГИС открывает только координаты назначения; положение посетителя приложение в ссылку не вставляет.

Sites ранее не опубликовал дизайн из-за ошибки доступа. Текущая сборка с Python API работает локально; онлайн-адрес не заявлен готовым. Для GPS на телефоне нужен HTTPS и разрешение браузера: https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/getCurrentPosition .
