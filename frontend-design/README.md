# Дизайн сайта Свой Владик

Адаптивная болванка веб-приложения **только для Ленинского района Владивостока**. Дизайн: белые панели, оранжевый акцент `#FF8500`, графитовый текст, светлая векторная карта с голубой водой. На ПК — боковая панель и карта; на телефоне — карта с раскрывающейся нижней панелью и навигацией.

Это отдельный статический прототип для согласования дизайна, не готовый MVP с сервером. Код основного приложения и задачи бэкенда не заменены.

Текущая версия стала компактнее: шапка 64 px, панель на ПК 360 px, меньше интервалы, названия мест 14–15 px и подписи 12 px. На телефоне список занимает больше полезной высоты, длинное название и кнопка выбранного места размещаются в отдельных строках. Добавлены отступы для вырезов экрана, переносы текста и прокрутка длинных окон; стартовая карта вмещает три точки с целыми подписями.

## Запуск

Требуется Node.js 18+; устанавливать npm-пакеты для этого примера не нужно.

```sh
cd frontend-design
node preview.mjs
```

Открыть `http://127.0.0.1:5173/`. Сервер доступен только локально и отдаёт файлы из `dist/`. Если порт занят, остановить предыдущий предпросмотр. Для карты, библиотеки и веб-шрифта нужен интернет; при отсутствии шрифта используется системный.

## Что работает

- Настоящая карта MapLibre с локально сохранённым стилем и открытой подложкой OpenFreeMap.
- Граница Ленинского района, три стартовые точки OSM, выбор точки и карточка места.
- Поиск по загруженным местам, категории, пустая выдача и сброс фильтров.
- Закладки и выбор простого аватара в localStorage, без регистрации и GPS.
- Вводное окно «Я тут впервые», статичный маяк-гид, переходы к источнику и во внешний пешеходный навигатор 2ГИС.
- Схема границы и список при невозможности создать WebGL-карту; схема не заменяет уличную навигацию.

Раздел прогулок показывает идею из трёх точек, не рассчитанный и проверенный маршрут. Раздел квестов честно сообщает, что первый квест готовится. У мест не выдуманы цены, часы работы и оценки: условия требуют редакторской проверки. Точки ещё кандидаты, а не verified-каталог основного API.

## Файлы и подключение к продукту

- `dist/index.html` — структура экранов и диалогов.
- `dist/styles.css` — цвета, компоненты и адаптация.
- `dist/app.js` — локальные взаимодействия и карта.
- `dist/map-style.json` — оформление настоящих географических слоёв.
- `dist/assets/` — оригинальные SVG маяка и условных виньеток мест.
- `dist/data/` — сохранённая граница и 3 OSM-кандидата для автономности прототипа от API.

Для основного фронтенда переносить выбранные компоненты и стили; загрузку статических кандидатов заменить согласованным [API](../docs/API.md). Не переносить в продукт непроверенные карточки автоматически. Этот пример buildless; React/TypeScript-архитектура команды остаётся отдельной задачей.

## Источники и безопасность

[MapLibre GL JS](https://maplibre.org/) 4.7.1 подключён с закреплённой версией CDN. Стиль основан на [OpenFreeMap Positron](https://openfreemap.org/quick_start/) и локально изменён под интерфейс. Сохраняются атрибуции OpenFreeMap/OpenMapTiles/OpenStreetMap; геоданные распространяются по [ODbL](https://opendatacommons.org/licenses/odbl/1-0/). Происхождение исходных слоёв — [data/geo](../data/geo/README.md). Иллюстрации оригинальные и условные, не фотографии объектов.

Нет серверных ключей, пользовательских загрузок, свободного HTML из данных или запроса геолокации. Ссылки ведут на фиксированные хосты OSM/2ГИС, координаты берутся из сохранённых данных. При включении настоящего API соблюдать [SECURITY](../docs/SECURITY.md), этот прототип сам по себе не доказывает готовность всего продукта.

## Проверка и публикация

Проверены синтаксис JS, загрузка реальных геослоёв и карточек, фильтр, пустой поиск, сохранение после обновления, вводное окно, выбранная точка и диалоги. В браузере проверены размеры 1440×960, 390×844 и 320×740 без горизонтального скролла; каталог содержит только точки Ленинского района. На подложке видны соседние улицы для географического контекста, переключения на другие районы нет. Ссылки построены по документированному формату, внешний маршрут не проходили на местности.

Компактная версия дополнительно проверена при 1280×720, 768×740, 390×844, 320×740 и 320×568: длинное название музея, окно знакомства, пустая выдача, сброс поиска и прокрутка до последнего примечания. Горизонтального переполнения в этих сценариях нет. CSS учитывает системные safe-area-inset; проверка на физическом iPhone с вырезом ещё нужна. [Вид на ПК](review/compact-desktop.jpg) и [вид на телефоне](review/compact-mobile.jpg).

Онлайн-публикация через Sites пока не выполнена: регистрация создана, но доступ к репозиторию исходников вернул HTTP 400, а локальный helper не поддержал выданный режим `codex_auth`. Приватный Site ID сохранён в `.openai/hosting.json` для продолжения той же публикации; регистрация и ожидаемый адрес не считаются работающим сайтом. Локальный прототип от публикации не зависит.
