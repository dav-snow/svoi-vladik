# Географическая основа

- `leninsky-boundary.geojson`: полигон OSM relation 1933824, Ленинский район Владивостока. Сохранён после однократного обращения к Nominatim. Это общественная граница, не юридическая выписка.
- `leninsky-poi-candidates.geojson`: 3 конкретных OSM-объекта после проверки вхождения представительной точки в полигон; не полный список района. Все записи `draft`, с источником, `checked_at=null` и `price_rub=null`. Часы и условия редактором не подтверждены.

Время импорта записано в GeoJSON. Для площадных объектов маркер не обязательно соответствует входу: его нужно проверить перед прокладыванием пути. Остановки, совпавшие по названию с искомым парком или фуникулёром, не приняты за сами объекты.

Эти записи не попадают в основной API, который по [контракту](../../docs/API.md) отдаёт только verified. Предпросмотр показывает их с явной пометкой. Для основного каталога участник 3 проверяет сведения и готовит собственное описание, участник 2 валидирует структуру. [Решение по карте](../../docs/MAP_LENINSKY.md).
