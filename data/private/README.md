# Приватная конфигурация квестов

`quest-answers.json` хранится только на сервере и исключён из Git. В текущем локальном рабочем окружении он уже подготовлен. Не добавляйте этот файл принудительно в публичный репозиторий и не копируйте в `frontend-design/dist`.

На новом сервере редактор создаёт локальный `data/private/quest-answers.json`, используя утверждённый набор вопросов. Шаблон — `quest-answers.example.json`. Схема:

```json
{"quests":{"quest-id":{"stop-id":{"correct_option_id":"option-id","explanation":"Пояснение редактора"}}}}
```

ID должны совпадать с публичным `data/quests.json`. Для каждого задания требуется запись. Сборка дополнительно проверяет конфигурацию, если она присутствует; содержимое не выводится. Без неё каталог и прогулки доступны, а API проверки квеста возвращает 503 с понятной ошибкой. Это конфигурация сервера, а не файл для браузера.

При Docker-развёртывании передавайте файл отдельно как read-only bind mount, не публикуйте образ с конфигурацией внутри. Локальная команда: `docker compose up --build` после подготовки файла. Награды локальные; этот проект не использует ответы как защиту соревновательного рейтинга.
