# Свой Владик

Веб-гид для новичка в Ленинском районе Владивостока: карта и каталог мест,
поиск «что рядом», готовые прогулки, исторические квесты с проводницей Владой,
практический гид (еда, туалеты, досуг), демо-аккаунт с лайками и посещениями,
обучение Влады, профиль с аватарами и личный маршрут.

**Текущее состояние:** рабочая сборка, а не макет. Карта, API, фото, прогулки,
квесты, аккаунты, аватары и маршрут реализованы; контент остаётся `draft` и
требует полевой проверки. Полный список того, что работает и что нет, —
[STATUS.md](docs/STATUS.md).

Публичный стенд: **https://176-53-253-60.sslip.io/** (HTTPS нужен для
геолокации). На момент обновления документации стенд отстаёт от `main` — нужен
повторный деплой.

## Что умеет

- **Карта и каталог.** MapLibre, граница Ленинского района, 17 кандидатов
  (14 отдаются API), поиск, категории, карточка места с фотогалереей.
- **«Что рядом со мной».** Одноразовая геолокация по кнопке, точность и время,
  радиус, ручной старт, честное предупреждение о плохой точности.
- **Фотографии мест.** 30 лицензированных изображений у 16 мест, автор и
  лицензия в подписи, ссылка на источник.
- **Прогулки.** 4 готовых прогулки по 3–5 точек, переход в 2ГИС, локальный
  прогресс.
- **Квесты.** 4 квеста по 3–5 остановок: истории, вопросы, итоговый опрос,
  серверная проверка ответов, локальный прогресс.
- **Практический гид.** 33 карточки «поесть / туалет / досуг» с источниками и
  честной пометкой «кандидат».
- **Демо-аккаунт.** Регистрация и вход, лайки, отметки посещений, профиль, топ.
- **Обучение Влады.** Знакомство с приложением, прогресс в аккаунте, показ один
  раз на браузер, повторно — через «Помощь Влады».
- **Аватары.** Шесть готовых образов: три сразу, компас/краб/мост — за 1/2/3
  разных завершённых квеста; выбор в профиле и аватар рядом с логином.
- **Личный маршрут.** 2–5 точек, старт от позиции/места/ручной точки, порядок,
  сумма по прямой, оценка времени, 2ГИС на каждом переходе.
- **PWA-основа.** Манифест и service worker; полноценный офлайн не обещаем.

Подробности и ограничения — [STATUS.md](docs/STATUS.md).

## Быстрый старт

Нужны Node.js 20+ и Python с зависимостями. Подробно — [RUN_LOCAL.md](docs/RUN_LOCAL.md).

```sh
# из корня проекта
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
npm start                  # http://127.0.0.1:8000/
```

`start.cmd` делает то же самое двойным щелчком. Остановить сервер — Ctrl+C в
окне запуска.

Проверки:

```sh
node --test frontend-design/tests/       # 62 теста
.venv\Scripts\python.exe -m pytest backend/tests -q   # 99 тестов
node scripts/build.mjs --check-only      # контент и публичные файлы
```

## Структура

```text
backend/              FastAPI: main.py, тесты, зависимости
frontend-design/      buildless-клиент: dist/{app.js,index.html,styles.css,...}, tests/
data/                 места, прогулки, квесты, гид, geo, media, private/
assets/               маскот, аватары, лицензированные фото мест
scripts/              start, build, импорт данных и подключение фото
docs/                 актуальная документация и исторические планы
prompts/              ТЗ задач, включая следующую редизайн-итерацию
worklog/              ежедневные отчёты
Dockerfile, docker-compose.prod.yml, Caddyfile, deploy.cmd
```

Фронтенд правится прямо в `frontend-design/dist/`; отдельной сборки нет.
После изменения публичных файлов пересчитайте `build-manifest.json`:
`node scripts/build.mjs`.

## Данные и честность

- Все места и гиды имеют статус `draft`: источники сверены онлайн, полевая
  проверка не выполнялась.
- Цена `null` означает «неизвестно», а не «бесплатно».
- Геолокация считается только в браузере; координаты не уходят в API, URL или
  `localStorage`.
- Прогресс квестов, аватары и личный маршрут хранятся на устройстве; между
  устройствами не синхронизируются. Это известное ограничение, не баг.
- Фото сохраняют автора и лицензию; общая лицензия кода их не заменяет.

## Публикация

Прод-сборка: `docker compose -f docker-compose.prod.yml up -d --build` (Caddy
терминирует HTTPS, SQLite живёт в named volume). Пошагово, включая ключи
ответов и откат, — [DEPLOY.md](docs/DEPLOY.md).

## Команда и процесс

Исходная команда — три роли: фронтенд/дизайн, бэкенд, продукт/контент/приёмка;
сейчас работа идёт с ИИ-агентами. Правила веток, ревью и коммитов —
[CONTRIBUTING.md](CONTRIBUTING.md), журнал ИИ — [docs/AI_USAGE.md](docs/AI_USAGE.md).

Лицензия кода не выбрана. Геоданные OSM — отдельно по ODbL
([data/geo/README.md](data/geo/README.md)); лицензии фотографий — в
[docs/PLACE_PHOTOS_AND_SUMMARIES.md](docs/PLACE_PHOTOS_AND_SUMMARIES.md).
