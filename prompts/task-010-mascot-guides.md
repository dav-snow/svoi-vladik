# Задача 010: маскот — практический гид (еда, туалет, досуг)

Делать **после** задачи 009, отдельной веткой: те же файлы `app.js`/`index.html`/`styles.css`.

## Что готово на бэкенде

`GET /api/v1/guides?need=eat|toilet|fun` (в `main`, PR #7):

```json
{"items":[{"id":"guide-t01","title":"Адмиральский сквер","need":"toilet",
"address":"Светланская, 48, Адмиральский сквер.","price_note":"",
"note":"Краткая справка и оговорки редактора","verification_note":"что проверить",
"source_url":"https://…","sources":[{"title":"…","url":"https://…"}],
"checked_at":null,"status":"draft"}],"total":5}
```

33 карточки: 10 еды, 5 туалетов, 10 досуга. Координат нет — на карте их показывать нельзя.

## Что сделать

1. Три кнопки маскота («Поесть», «Туалет», «Досуг») вместо заглушек вызывают
   `/api/v1/guides?need=eat|toilet|fun` и открывают список карточек.
2. Карточка в списке: название, адрес, если есть `price_note` — «Цена по справочнику:
   …», кнопка «Источник» (внешняя ссылка, `rel="noopener noreferrer"`), при наличии —
   `verification_note` мелким текстом.
3. Подпись над списком, обязательная и честная:
   «Кандидаты из справочников. Работу, вход и цены не подтверждали».
4. Состояния: загрузка, ошибка сети с кнопкой «Повторить», пустая выдача.
   Для пустого туалетного результата использовать текст из
   `docs/PRACTICAL_CITY_GUIDE.md`: «Рядом есть несколько санитарных точек из
   справочников, но их работу сейчас мы не подтвердили. Не хочу отправить тебя
   к закрытой двери.»
5. Никаких маркеров на карте и никаких «проложить маршрут до этой точки»: координат нет.
   Ссылка «Искать в 2ГИС» допустима только как поиск по адресу текстом, не по координатам.
6. Маскот использует свои шесть состояний (`mascot.js`) — показать уместное: загрузка,
   пусто (`location-unknown`), результат (`directions`).
7. Не трогать сценарий квеста, GPS, избранное, прогресс. Не менять бэкенд и данные.

## Ограничения

- Разрешённые пути: `frontend-design/dist/app.js`, `index.html`, `styles.css`.
- Запрещено: `backend/**`, `data/**`, `docs/**`, `assets/**`, `mascot.js`, `mascot.css`, `sw.js`.
- Не добавлять библиотеки. Тексты карточек выводить как текст, не как HTML.

## Критерий приёмки

- `node --check`, `npm run build`.
- Вручную на 390×844 и 1440×960: три кнопки открывают свои списки; у туалетов 5 карточек,
  у еды 10; источник открывается; пустая выдача показывает честный текст; ошибка сети
  даёт «Повторить».
- На карте новых маркеров не появилось.
- Скриншоты трёх списков в отчёте.
