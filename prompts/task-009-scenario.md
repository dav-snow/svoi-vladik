# Задача 009: сценарий — обход, итоговый опрос, финал без наград

## Что изменилось в требованиях

1. **Двухфазный квест** (`docs/DEMO_CONTENT.md`, `docs/ROUTES_AND_QUESTS_V2.md`, коммит `33e7b3e`):
   сначала обход остановок без вопросов, затем один общий опрос, затем завершение.
2. **Аватарки и кастомизация исключены полностью** (`b88a6d4`, затронуты `docs/CONCEPT.md`,
   `docs/API.md`, `README.md`): нет выбора персонажа, шапок, аксессуаров, магазина,
   коллекций. Маскот-проводница остаётся, это не аватар пользователя.
3. **Предметные награды не показываем.** `POST /complete` всё ещё возвращает `reward`
   в старом формате — фронтенд его игнорирует и показывает финал без предмета.
4. **Проверка «рядом» перед отметкой** (требование владельца): отметить остановку можно,
   только если устройство в радиусе 150 м от точки.

## Что уже готово на бэкенде (не менять)

- `GET /api/v1/quest` → `{items: Quest[]}`; в `stops[]` есть `fact_text`, `fiction_text`,
  `question`, `options[]`, `sources[]`. Правильных ответов в выдаче нет.
- `POST /api/v1/quest/{quest_id}/answer` `{stop_id, option_id}` → `{correct, explanation}`.
- `POST /api/v1/quest/{quest_id}/complete` `{answers:[{stop_id,option_id}]}` → `{completed, reward}`.
  Поле `reward` игнорировать.
- Данные: 4 квеста (два по 3 остановки, два по 5).

## A. Единый механизм обхода

1. Один компонент прогресса для прогулок и квестов: «Остановка N из M», кнопка
   «Я на месте», чек-лист с отметками, «Завершить» после последней.
2. Плашка прогресса видна поверх карты на телефоне и десктопе; не перекрывает зум,
   атрибуцию и safe-area.
3. При старте не сворачивать сайдбар: сейчас `startWalk` → `selectPlace` →
   `is-collapsed` на мобильном скрывает управление — это баг.
4. Сохранять `done: string[]` с ID пройденных; перезагрузка восстанавливает отметки;
   «Завершить» очищает.

## B. Двухфазный квест

5. Экран остановки: `fact_text`, `fiction_text`, источник, кнопка «Я на месте».
   **Вопроса и вариантов на этом экране нет.**
6. После последней отметки — экран «Обход завершён N/N» и кнопка «Начать итоговый опрос».
7. Опрос: вопросы по одному, `POST /answer`; неверный ответ показывает пояснение и
   разрешает повтор; верный отмечает вопрос и ведёт к следующему.
8. Когда все ответы верны — `POST /complete`. Если `completed: true` — экран
   «Квест завершён» **без предметной награды**: только название квеста, «пройдено N из N»
   и кнопка «К другим квестам». Поле `reward` не показывать и не сохранять.
9. Хранение: `progress.quests[id] = { visited: string[], answers: {stopId: optionId}, completed: boolean }`.
   Повторный вход возвращает в актуальную фазу: обход → опрос → финал.
10. Сброс очищает `visited`, `answers`, `completed`.

## C. Проверка «рядом» (GPS)

11. Перед «Я на месте» сравнить позицию устройства с координатами остановки
    (уже есть `geo.lat/lng` и `haversineM`). Радиус — 150 м:
    - ближе: кнопка активна, подпись «Вы рядом с точкой (≈N м)»;
    - дальше: кнопка недоступна, подпись «До точки ≈N м» и ссылка «Идти в 2ГИС»;
    - `accuracy > 150`: предупредить о неточности, но не блокировать.
12. Если геолокация недоступна, запрещена, ошибка или таймаут — показать кнопку
    «Отметить без проверки» с подписью «Без проверки рядом». Демо не должно упираться
    в тупик из-за разрешения браузера.
13. В прогрессе хранить `verifiedByGps: boolean` для каждой отмеченной точки;
    в чек-листе пройденные без проверки помечать отдельно и подписывать.
14. Формулировки честные: «вы рядом с точкой», а не «посещение подтверждено».
15. Координаты, точность и время не уходят на сервер, не пишутся в URL и логи.

## D. Удалить аватар и предметные награды

16. Убрать кнопку аватара в шапке (`#avatar-open`), диалог выбора образа
    (`showAvatar`, `avatar-options`), карточку «Шапка исследователя» и класс `has-reward`.
17. Убрать `progress.rewards` и запись `explorer-hat`; старые значения в `localStorage`
    игнорировать, не падать на них.
18. В сохранённом состоянии остаются только: избранное, выбранный старт/позиция,
    прогресс прогулки, прогресс квеста. Всё остальное — удалить.
19. `README`/доки не править: это зона У3.

## Критерий приёмки

- `node --check frontend-design/dist/app.js`, `npm run build`.
- Вручную на 390×844 и 1440×960:
  - квест: обход без вопросов → «Обход завершён» → опрос → неверный ответ даёт пояснение
    и повтор → финал без предметной награды;
  - рядом/далеко по координатам: кнопка доступна/недоступна, расстояние показано;
  - отказ в геолокации: квест проходится через «Отметить без проверки»;
  - перезагрузка на середине обхода и опроса возвращает в ту же фазу;
  - сброс обнуляет прогресс;
  - аватара и шапки в интерфейсе нет, старый `localStorage` не ломает приложение;
  - прогулка: та же плашка, галочки, «Завершить»;
  - GPS «Что рядом со мной», избранное, маскот, карта работают как раньше.
- В Network за обход нет POST; запросы к `/answer` начинаются только на опросе.
- Скриншоты фаз и финала в отчёте.
