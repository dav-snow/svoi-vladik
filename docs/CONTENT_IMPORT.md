# Импорт мест, прогулок и квестов

13 ноября 2026. Источники: DEMO_CONTENT.md, ROUTES_AND_QUESTS_V2.md, сохранённые OSM-данные и ссылки каждой карточки. Авторские игровые реплики отделены от справок. Подробности происхождения координат сохранены в data/places.json; повторного онлайн-геокодирования в приложении нет.

## Результат

- 17 уникальных кандидатов в data/places.json; API показывает 14 активных карточек внутри сохранённого полигона Ленинского района OSM. Все имеют статус draft: это не проверка входа, работы или доступности.
- 4 прогулки: «Три повода выйти из дома», «Город с характером», «Пять историй одного города», «От сцены к морю». Две содержат 3 остановки, две — 5.
- 4 квеста: исходный OSM-квест, «Три ключа от города», «Письмо из Владивостока», «Код города». Всего 16 заданий. У каждого вопроса есть источник; 16 ответов и пояснений находятся в data/private/quest-answers.json, вне HTTP-статики.
- Цены, часы, длительность и длина пути не выдуманы. null не означает бесплатный вход. Пунктир показывает последовательность остановок; настоящий пешеходный путь до выбранной точки открывается в 2ГИС.

## Неактивные кандидаты

| ID | Причина |
|---|---|
| eagle-view | Найден пик Орлиное Гнездо, но не подтверждённая общедоступная смотровая площадка. |
| stone-lions | Координаты скульптур не подтверждены; координаты здания не подменяют точку львов. |
| minny-park | Не определена конкретная доступная зона и безопасный подход при изменяющихся условиях реконструкции. |

«На уровень выше» не включена в рабочие прогулки: её финальная площадка не подтверждена. «Свои у моря» остаётся однолокационным игровым сценарием в документации, а не пятью разными местами. Фуникулёр представлен одной карточкой: метка станции не гарантирует расположение входа, поездка для квеста не обязательна.

## Проверка и ограничения

Координаты сверены одноразово по адресным данным и объектам OpenStreetMap. Для ворот использован точный node 296115500, а не соседний дом. Принадлежность активных точек проверяет сборка с учётом внутренних колец полигона. Общественная граница OSM не является юридически удостоверенной границей района.

Факты снабжены первичными музейными/туристическими источниками и карточками Культура.РФ. Источники находятся рядом с фактами в JSON и видны в интерфейсе. Пешеходные переходы, входы, доступ к музейным территориям, стоянка «Красного вымпела» и текущая работа фуникулёра требуют проверки командой на местности. Не выдаём сценарии демо за проверенные прогулки.

Для одноразового фиксированного списка соблюдался интервал запросов Nominatim; ответы сохранены в данных. Журнал исходной сверки оставлен локально в .local/content-import-lookups.md. Пользовательские координаты геокодеру не отправляются. Политика: https://operations.osmfoundation.org/policies/nominatim/ . Координаты OSM — ODbL; атрибуция в карте и data/geo/README.md сохранена.

Приватные ответы не выдаются HTTP API и не входят в сборку фронтенда. Публичный GitHub содержит исходники демо: этот механизм не предназначен для соревновательной защиты от читов или серверного рейтинга. Награда и прогресс локальные, посещение GPS не удостоверяет.
