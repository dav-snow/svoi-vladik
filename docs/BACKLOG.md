# Бэклог версии на 36 часов

Все задачи **запланированы**, приложение ещё не написано. P0 — ограниченное демо из [CONCEPT.md](CONCEPT.md), P1 — только после готового P0 и до заморозки H27. H0 — общий старт. Старый план на 15 мест/48 часов заменён. У1 — дизайн+фронтенд, У2 — бэкенд, У3 — продукт+контент+приёмка.

География всех задач — **только Ленинский район Владивостока**: 8 мест, обе прогулки и квест на одном компактном участке внутри него. У3 проверяет районную принадлежность карточек; У1 и У2 используют этот каталог без расширения на другие районы при смене радиуса. Возможные события P1 также только в Ленинском районе.

## Отсечение объёма

Если к H8 нет общего клиента/API/раннего стенда — сначала исправить интеграцию, отложить весь P1. К H12 при отставании принять сокращённый вариант 6 мест/1 прогулка; записать это в README демо и рассказ на защите. Квест, источники, безопасные ошибки и основные проверки сохраняются. К H27 закрыть новые функции. Список блокеров — [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md), расписание — [IMPLEMENTATION_36H.md](IMPLEMENTATION_36H.md).
