# Начальный бэклог

Статус всех задач: **запланировано**. Это подготовка к разработке, а не отчёт о готовых функциях. Заведите задачи в GitHub Issues, когда команда подтвердит срок и стек.

**P0** — нужен для цельного MVP и защиты. **P1** — улучшение после рабочего MVP. Порядок задач отражает зависимости, а не жёсткую очередь: дизайн, контент, API и интерфейс выполняются параллельно после согласования контракта.

## Минимальный набор проверок для SV-10

Приёмку ведёт участник 3 по [ROLE_3.md](ROLE_3.md). Он фиксирует ожидаемый и фактический результат, шаги, устройство и серьёзность дефекта; разработчики исправляют свои части. Технические проверки кода и API остаются ответственностью разработчиков.

1. Новый пользователь выбирает интересы и бюджет, получает подходящие места и открывает источник карточки.
2. Запрос без совпадений показывает понятное сообщение и возможность сбросить фильтры.
3. Бесплатное событие имеет подтверждение организатора; истёкшие события не маскируются под будущие. Если нет актуальных записей, интерфейс сообщает об этом.
4. Без геолокации пользователь выбирает старт вручную; внешняя навигация получает координаты выбранного места.
5. Исторический квест проходит все три точки; ответ и объяснение совпадают с содержанием источника; прогресс не теряется после обновления страницы.
6. Подбор работает по фильтрам без подключения модели. Если реализован P1 с ИИ, отказ сервиса оставляет доступным обычный подбор, а ответ с неизвестным `id` не создаёт выдуманную карточку.
7. Сетевой сбой не оставляет бесконечную загрузку: есть сообщение и повторная попытка.
8. Участник команды запускает проект с нуля по README, используя только опубликованный пример конфигурации и собственные локальные секреты.

## Что не добавляем до готового P0

Аккаунты и социальную сеть, чат между пользователями, пользовательские публикации и модерацию, собственный транспортный роутинг, рейтинги и соревнования, массовую генерацию квестов, постоянное отслеживание геопозиции и автоматический сбор афиш. Аудиоистория — следующая итерация: для подготовки достаточно текстового квеста, который уже объединяет три темы.
