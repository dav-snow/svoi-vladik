# Проверка интегрированной сборки

13 ноября 2026. Проверял Codex в Windows. Это проверка работоспособности демо, а не полевой приёмки мест или публичного production-развёртывания.

## Состав

14 активных draft-карточек из 17 кандидатов, 4 прогулки на 3/3/5/5 остановок, 4 квеста на 3/3/5/5 заданий. Все активные координаты внутри сохранённого OSM-полигона с учётом внутренних колец. Источники и исключения: [CONTENT_IMPORT](CONTENT_IMPORT.md).

## Выполнено

- 31 тест FastAPI: контракт, неизвестные ID, формат ошибок, испорченный JSON, NaN/Infinity, неактивные/внерайонные карточки, скрытие правильных ответов в публичной выдаче, отказ в HTTP-доступе к private, проверка каждого ответа и всех 3/5 заданий перед наградой, лимиты тела/частоты и отсутствие CORS wildcard.
- 8 Node-тестов GPS с синтетическим navigator: запрос только по действию, HTTPS, отказ, таймаут, поздние callback, ручной выбор во время запроса, новое определение, валидация координат/точности, отсутствие передачи или сохранения позиции. Настоящий GPS не вызывался.
- Браузер: квест «Код города» полностью пройден, включая неверный ответ, повтор, перезагрузку после первого задания, продолжение и награду только после пятого. В профиле виден открытый аксессуар.
- Прогулка «Пять историй одного города»: пять пронумерованных точек, ссылка на текущую остановку в 2ГИС, сохранение после обновления, все пять ручных отметок и завершение. Метки ручные, а не GPS-доказательство прибытия.
- Ручной старт: расстояние до выбранной карточки ≈0 м; сортировка, радиус 300 м, переключение на все 14 мест, сохранение режима «весь каталог» при смене радиуса и очистка позиции.
- Размеры 1280×800, 390×844, 320×568: горизонтального переполнения нет, текст помощницы внутри панели, короткое окно прокручивается и остаётся в границах экрана. Реальные WebP загружаются; режим reduced-motion предусмотрен CSS.
- Сборка проверяет JSON, ссылки и синтаксис, наличие ассетов, отсутствие ответов во фронтенде, целостность связей и границу активных мест. Создаётся только публичный build-manifest с размерами и SHA-256.
- Новый launcher реально запустил API на 127.0.0.1:8000; повторный запуск переиспользует наш сервер. start.cmd --help проверен. Старый :5173 работает как прокси, отдельного источника данных нет.

## Повторить

```text
npm.cmd test
npm.cmd run build
npm.cmd start
```

Тесты используют локальную .venv, npm-зависимостей нет. В ограниченной песочнице Windows TestClient требовал разрешённого loopback; тесты выполнены с разрешением. Есть одно предупреждение об устаревающем httpx в Starlette TestClient, сбоев тестов нет.

## Остаётся ручная приёмка

GPS физического телефона и системный диалог разрешения, установка PWA на реальный iPhone/Android, HTTPS публичного стенда, отсутствие WebGL, реальные пешеходные переходы/входы, текущие часы и цены. Путь строит внешний 2ГИС; внутри карты — только схема порядка. Онлайн-размещение не заявлено готовым. Сервер слушает localhost, Docker по умолчанию также привязан к loopback.

Ответы защищены от выдачи HTTP и попадания в статику. Исходники публичного демо доступны на GitHub: это не защита соревнований от читов. Регистрации, рейтинга и серверной истории перемещений нет.

Автоматическая проверка не разрешила публикацию реального `data/private/quest-answers.json`. Он сохранён локально, исключён из Git и образа Docker. В публичной ветке нет его истории; для нового сервера добавлены пустой шаблон и инструкция, существующая локальная сборка продолжает проверять все ответы.
