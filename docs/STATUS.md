# Состояние проекта «Свой Владик»

Актуально на 14 ноября 2026. Код в `main` — задачи 015–023 (редизайн 022,
синхронизация аватаров и лицензии фото 023). Дальнейшая работа — в отдельных
ветках по [BACKLOG.md](BACKLOG.md). Этот документ описывает **фактическое**
состояние, а не план вайбатона.

## Что это

Веб-гид для новичка в Ленинском районе Владивостока: карта и каталог мест,
поиск «что рядом», готовые прогулки, исторические квесты с проводницей Владой,
практический гид (еда, туалеты, досуг), демо-аккаунт с лайками и посещениями,
обучение Влады, профиль с аватарами и личный маршрут.

Один origin: FastAPI отдаёт `/api/v1/*`, статический фронтенд, фото и карту.
Публичный стенд — **https://176-53-253-60.sslip.io/** (HTTPS обязателен для
геолокации).

## Данные

- `data/places.json` — **17 кандидатов, 14 отдаются API** (`active` +
  `district_verified` + статус `draft`/`verified`). Все статусы — `draft`:
  полевая проверка не выполнялась.
- `data/routes.json` — 4 прогулки, `data/quests.json` — 4 квеста.
- `data/guides.json` — 33 карточки справочника; координат входа нет.
- `data/private/quest-answers.json` — серверные ключи ответов, в Git не входит.
- `assets/places/` — лицензированный фото-пак (WebP/JPEG + манифест),
  подключается скриптом `scripts/link_place_photos.py`.
- `frontend-design/dist/assets/avatars/` — 6 WebP-аватаров из архива
  `assets/avatars/`.

## Технически

- **Клиент:** buildless-фронт без сборщика: `frontend-design/dist/` с
  `app.js` (~1,8 тыс. строк), `motion.js`, `mascot.js`, CSS-слоями и MapLibre
  4.7.1 с CDN. Правки — прямо в dist, `node scripts/build.mjs` считает хэши в
  `build-manifest.json`.
- **Сервер:** один `backend/main.py` на FastAPI: Pydantic-модели, загрузка
  JSON, SQLite для демо-аккаунтов/сессий/лайков/посещений/обучения/завершённых
  квестов/аватаров, rate-limit, security headers, статические монтирования
  `/assets/places`, `/media`, `/data`, `/`.
- **Проверки:** `node --test frontend-design/tests/` (72 теста) и
  `python -m pytest backend/tests` (109 тестов); GitHub Actions гоняет
  pytest, node-тесты и `build.mjs --check-only`. Есть браузерный
  `scripts/smoke-e2e.mjs` (12 проверок: desktop/mobile, аватары, лицензия,
  PWA и офлайн-оболочка) и `scripts/audit_content.py`.
- **Деплой:** `Dockerfile`, `docker-compose.prod.yml`, Caddy + HTTPS,
  named volume для SQLite; инструкция — [DEPLOY.md](DEPLOY.md).

## Безопасность

Демо прошло внутреннюю проверку, не пентест. Реализованы scrypt, серверные
сессии в HttpOnly/Secure/SameSite=Lax cookie, rate-limit, валидация, параметризованный
SQL, `no-store` для API, `X-Frame-Options`, COOP, CSP в Report-Only и HSTS в
Caddy; широкий `/data` не раздаётся. Остаточные риски и чек-лист — в
[SECURITY.md](SECURITY.md): CSP пока не блокирует, лимиты в памяти одного
процесса, контейнер root, зависимости не зафиксированы lockfile, импорт квестов
доверяет клиенту.

## Что не проверено / известные ограничения

- Полевая проверка мест, часов работы, цен и проходов — не выполнялась.
- Реальный GPS на телефоне и живые переходы в 2ГИС — только синтетические
  тесты и браузерная проверка; приёмка за третьим участником.
- Аватары, выбранный образ и факт завершения квестов синхронизируются через
  аккаунт. Детальный прогресс обхода (посещённые точки и ответы) и личный
  маршрут остаются в `localStorage`.
- Нет email, восстановления пароля, 2FA, удаления аккаунта.
- Завершение квеста возвращает только `completed`; предметных наград нет.
- Деплой и бэкап автоматизированы скриптами, но ключ есть только у владельца.
- PWA не обещает офлайн-карту; service worker кэширует только оболочку.
- Контентные статусы `draft`, у гида нет координат входа; структурный аудит
  пройден, полевая проверка — нет ([CONTENT_AUDIT.md](CONTENT_AUDIT.md)).
