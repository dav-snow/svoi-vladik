# Журнал использования ИИ

Задача вайбатона — создать проект с помощью ИИ. Требования организаторов пока не предоставлены: команда должна проверить, какие доказательства и инструменты допустимы. Использование ИИ в разработке и наличие модели внутри приложения — разные решения; runtime-подбор запланирован как P1.

Открытие официальных источников и сверка согласованности документов выполнены ассистентом. Это не заменяет редакторскую проверку городских данных человеком. Реальные карточки и готовый квест ещё не созданы.

Каждый участник добавляет записи о своей работе: участник 1 — о дизайне и фронтенде, участник 2 — о бэкенде, участник 3 — об интервью, обработке контента и подготовке защиты. Участник 3 собирает журнал и выбирает один понятный пример для презентации; автор работы отвечает за точность своей записи. Тексты городских фактов проверяет редактор по первоисточникам, код проверяют разработчики. Использование ИИ для черновика не означает, что задача уже принята человеком.

## Дизайн сайта

Интеграция, 13.11.2026: Codex объединил дизайн с командной веткой FastAPI/GPS, импортировал согласованные места, прогулки и вопросы из документов с онлайн-сверкой источников и геометрии. Подключены шесть оптимизированных состояний помощницы (WebP, оригиналы сохранены), ручной старт, одноразовая геолокация, серверная проверка квестов, локальный прогресс/награда и единый запуск. Реальные переходы и физический GPS телефона не проверялись. Фактические проверки, ограничения и скриншоты — [INTEGRATION_QA.md](INTEGRATION_QA.md), исключения контента — [CONTENT_IMPORT.md](CONTENT_IMPORT.md). Подготовлены 31 backend-тест и 8 синтетических GPS-тестов, все проходят; пользовательские координаты не использовались.

Компактная версия, 13.11.2026: по просьбе команды Codex уменьшил шапку, ширину панели и интервалы, увеличил мелкие подписи и названия мест, добавил safe-area отступы, переносы и прокрутку. На телефоне кнопка выбранного места вынесена в отдельный ряд; сообщения карты собраны в стек, а стартовый масштаб учитывает список и подписи всех трёх точек. Проверены JS-синтаксис, отсутствие горизонтального переполнения при 1280×720, 768×740, 390×844, 320×740 и 320×568, длинная карточка, окно знакомства, пустой поиск, сброс и доступность последнего примечания при прокрутке. Отдельный агент просмотрел diff без обнаружения блокеров. Скриншоты сохранены в `frontend-design/review/`; физическое устройство с вырезом не проверялось.

Дизайн сайта, 13.11.2026: Codex подготовил адаптивную оранжево-белую оболочку, стиль карты и оригинальные SVG. Проверены синтаксис, основные локальные взаимодействия, сохранение и размеры ПК/телефона; найденные мобильные ошибки исправлены. Использованы только три сохранённые точки Ленинского района. Основной бэкенд и рабочий квест не реализованы в рамках дизайн-болванки. Онлайн-публикация Sites пока заблокирована ошибкой доступа к исходникам HTTP 400; ожидаемый адрес не заявлен как опубликованный.

## Правила команды

- Давать ИИ небольшую задачу с контекстом, контрактом и критерием готовности; читать ответ перед включением в проект.
- Не запускать несколько агентов на тех же файлах. Для отдельной задачи фиксировать ветку/worktree, разрешённые пути, запрет изменений API без согласования и ожидаемую проверку; порядок — [PARALLEL_WORK.md](PARALLEL_WORK.md).
- ИИ помогает подготовить вопросы и свести реальные ответы интервью; не придумывает исследование, отзывы или результаты тестов. Участник 3 сохраняет фактическое число разговоров.
- Код запускать и проверять по пользовательскому сценарию; важные ошибки и ограничения описывать в PR.
- Исторические утверждения, цены, расписания и существование мест проверять по первичным источникам, а не по уверенности ответа модели.
- Не отправлять секреты и личные данные в запросы; не коммитить необработанные логи с такими сведениями.
- Для иллюстраций и аудио фиксировать происхождение и условия использования. Художественные реплики не представлять как исторические свидетельства.
- На защите показать конкретный пример: запрос → результат ИИ → исправление команды → проверка. Не приписывать ИИ или себе несуществующую работу.
