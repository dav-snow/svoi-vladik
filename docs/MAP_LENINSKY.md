# Карта Ленинского района Владивостока

**Выбор: Leaflet 1.9.4 + OpenStreetMap + отдельный слой наших точек.** Это настоящая интерактивная карта с координатами. Оранжево-белыми делаем панели, маркеры и карточки; улицы не рисуем нейросетью. [Leaflet 1.9.4 stable](https://leafletjs.com/reference-1.9.4.html).

## Бесплатность и качество

[Данные OSM открыты по ODbL](https://www.openstreetmap.org/copyright). Для небольшого прототипа можно использовать стандартные тайлы `https://tile.openstreetmap.org/{z}/{x}/{y}.png` при соблюдении [условий](https://operations.osmfoundation.org/policies/tiles/): видимая атрибуция, обычное кеширование, без массового скачивания и предзагрузки. У сервера нет гарантированного SLA; бесплатность данных не означает безлимитный хостинг. Масштабируемая карта подходит лучше большого PNG.

Если позже понадобится полностью менять цвета улиц, подойдёт [MapLibre](https://maplibre.org/projects/gl-js/) с векторным источником и стилем. Сейчас это лишняя настройка: основной приоритет — точки интереса.

## Граница и точки

Подтверждён **OSM relation 1933824** — Ленинский район Владивостока, `admin_level=9`. [Карточка](https://www.openstreetmap.org/relation/1933824), [первичный API](https://api.openstreetmap.org/api/0.6/relation/1933824.json). [Граница GeoJSON](../data/geo/leninsky-boundary.geojson) — общественная картографическая граница OSM; её юридическую точность не заявляем. Действующую геометрию администрации подтвердить не удалось.

Обзорный bbox: юг/север `43.0974826…43.1499040`, запад/восток `131.8843306…132.0481927`. Внутри проверяется сам полигон, а не только прямоугольник.

[Стартовые точки GeoJSON](../data/geo/leninsky-poi-candidates.geojson): **3 кандидата** — Военно-исторический музей Тихоокеанского флота, Приморский драматический театр имени Максима Горького и Фуникулёр. Это выборка OSM для предпросмотра, не полный справочник и не verified-каталог MVP. Все записи `draft`, `checked_at=null`, `price_rub=null`. Условия, часы, бесплатность и входы ещё проверяет редактор.

Публичные Overpass-серверы вернули перегрузку/таймауты; бесконечных повторов не делали. Для нескольких конкретных названий однократно уточнены и сохранены результаты Nominatim. [Его ограничения](https://operations.osmfoundation.org/policies/nominatim/): один поток, максимум 1 запрос/с, кеширование; не использовать для автодополнения и скачивания всех POI. **Nominatim не встроен в приложение:** поиск в предпросмотре только по локальным данным.

Остановки с названием «Фуникулёр» или «Минный городок» не выданы за сами достопримечательности/парк. Для площадных объектов сохранена представительная точка, не гарантированный вход. Участник 3 выбирает и проверяет 8 полезных мест, участник 2 переносит принятые записи в основной API. Кандидаты сами по себе не получают статус verified. [Лицензия и происхождение данных](../data/geo/README.md).

## Самые простые маршруты

Сейчас **точка → карточка → «Пешком в 2ГИС»**. Ссылка передаёт только цель, GPS приложение не запрашивает. [Официальный актуальный формат 2ГИС](https://help.2gis.ru/question/razrabotchikam-zapusk-ideystviya-vmobilnom-prilozhenii-cherez-deeplink):

```text
https://2gis.ru/directions/tab/pedestrian/points/|<longitude>,<latitude>
```

Старт человек выбирает во внешнем сервисе. Мы не гарантируем самый быстрый путь, отсутствие лестниц или доступность входа. Прямая линия между точками не является рассчитанным маршрутом. Если понадобится путь внутри нашего интерфейса, отдельно подключим пешеходный движок. Публичный [FOSSGIS/OSRM](https://routing.openstreetmap.de/about.html) ограничивает обращения 1 запросом/с и ведёт журнал запросов; автомобильный `/driving` не выдаём за пеший профиль. Собственный routing-сервер сейчас не строим.

Для основного приложения предусмотрена отдельная [интеграция геолокации и поиска рядом](GEOLOCATION.md): по разрешению посетителя позиция используется локально для расстояний и сортировки районного каталога. Это следующий шаг реализации; приведённый здесь предпросмотр карты пока GPS не запрашивает. Во внешнюю навигацию по-прежнему передаём только цель.

## Предпросмотр

[prototypes/leninsky-map/index.html](../prototypes/leninsky-map/index.html): реальная подложка, граница, 3 маркера, карточки, категории, локальный поиск и внешние ссылки. Это отдельный пример, не всё приложение. При сбое карты остаётся список. Для загрузки GeoJSON нужен HTTP-сервер из корня репозитория:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000/prototypes/leninsky-map/`. Команда только для локальной проверки, не публичного хостинга; CDN/тайлы требуют интернета. Геоданные уже сохранены, при открытии не запускается новая выгрузка POI.

В текущей сессии проверены синтаксис JS и структура геоданных. Визуальный прогон в браузере не завершён: локальный адрес не открылся из среды проверки. Это ограничение проверки, а не подтверждение готовности карты к демонстрации. Перед подключением к основному приложению открыть страницу на устройствах команды и проверить тайлы, клики и внешнюю навигацию.
